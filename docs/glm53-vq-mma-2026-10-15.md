# GLM VQ grouped register MMA candidate

The opt-in `DS4_GLMVQ_MMA=1` path removes whole-expert BF16 weight
materialization during prefill. Default remains off pending text-quality
qualification. Decode keeps the retained restore path.

The retained whole trace attributed 72.16% of prefill wall time to routed
VQ restoration and GEMMs. This candidate groups tokens by expert, shares
the routing/input preparation, restores weights in registers and feeds
BF16 `mma.m16n8k16`. A persistent CTA retains the packed 64 KiB E4M3
codebook; up projection and SwiGLU share a kernel. Gain, clamp and BF16
boundaries remain; accumulation order changes.

The selected tile has 256 output rows, 32 expert tokens and 16 warps.
It uses 94 KiB dynamic shared memory, 128 registers/thread and no spills
on the recorded sm_121a build. Grouped activations/worklists add
144.094 MiB at chunk 512. Shape/format/alignment/resource checks retain
restore+GEMM fallback. E4M3 is codebook storage, not FP8 arithmetic.

Mapping fixtures and 991,232 actual output values passed independent FP64
dot checks. Bounds account for BF16 MMA accumulation, reduction order and
the BF16 output half-ULP. They do not require identity to cuBLAS, whose
reduced-precision accumulation differs. Isolated actual-layer timings
improved approximately 4.5–6x; cache/routing details remain in the local
replay receipts.

Conditions: identical original VQ artifact, binary and linked libraries;
1,984 raw code-prompt tokens, 32 forced non-EOS greedy decode transitions,
context 2,048, chunk 512, MTP/capture off, one in-process VMM owner.
Observed busy clocks were 2,184–2,190 MHz under the unchanged 300–2,200 MHz
policy. [Evidence](evidence/glm53-vq-mma-2026-10-15.json) records each arm,
source hashes and a failed loading arm excluded from the comparison.

All four successful runs generated the same 32 IDs. Frontier KL was
6.59e-8, but this sharply peaked frontier does not establish general quality.
The six-case text controls completed; the candidate quality process was
stopped by the unchanged PSI guard during weight loading, before inference.
That missing quality result prevents default adoption. Existing Korean
summary formatting/truncation and width-dependent code-format failures
are recorded baseline behavior, not passing quality results.

This evidence covers bounded 2K eager text arithmetic. It does not qualify
8K, MTP, vision, graphs, state reuse, API behavior or a Q4_K derivative.
