# v0.1.4: model and VQ support, inference work and audit repairs

This release collects changes since `v0.1.3`: 51 merged PRs through #110,
followed by the 23 audit/cleanup commits and ACL review correction in
[PR #112](https://github.com/Baekpica/ds4-dfm-rs/pull/112), and release metadata.
The cleanup baseline is `02a6b5be`, implementation `4a6d030d`, and evidence
report `dc03745e`. The release preparation changes version metadata and
documentation; it introduces no additional inference path.

MiniMax-H3 video/audio generation in
[PR #111](https://github.com/Baekpica/ds4-dfm-rs/pull/111) is excluded and
reserved for a later release. Existing image, audio and video **input**
support belongs to the model-specific contracts below.

## Performance and conversion tools

The cumulative changes include Inkling cold-prefill work, MiMo text/media
and MOPD campaigns, Naive and IQuest work, Qwen multi-image processing,
GLM resident/SSD and VQ campaigns, Ling prefill/latent-KV changes, Beam
prefill/decode work, MiniMax prefill/decode/DSpark work, and DeepSeek V4.1
text/vision campaigns. [Performance references](../performance.md) and the
[dated evidence index](../README.md#recorded-evidence) retain exact builds,
artifacts, numerical contracts, accepted costs and rejected candidates.
Their measurements are not a common-baseline or final-release speedup.

[VQ calibration](../vq-calibration.md) adds `tools/vq_calib/`: streamed
activation statistics, weighted codebook training/assignment/row gains,
9/10-bit GVQ v2, importance-weighted Q4_K nonexperts, and run-identity
checks across collection, conversion and assembly. It also includes the
DeepSeek V4.1 calibration/reference and DQVL conversion tooling used for
the 1017 iVQ artifact. A.X-K2 conversion support does not add an A.X-K2
runtime family.

## Host reliability and cleanup

The [audit ledger](../benchmarks/2026-10-26-ponytail-audit/README.md)
maps all 19 repaired defects to regressions. It covers FFI and malformed
GGUF bounds, native-failure state invalidation, atomic file/KV replacement,
post-approval edits, artifact-bound streamed checkpoints, single-reader
distributed snapshots, partial frames, connection/result cleanup,
Completion final flush, continuation/tool metadata, independent shell
deadlines and bounded log reads. Earlier merged changes also repair invalid
UTF-8 output, EOS/reasoning finish handling, serial-bank admission and
imported-weight coverage/catalog types.

The cleanup reuses the server worker entry, removes the always-admit
governor hook and copied QA approval gate/report, and consolidates 174
identical Make rules with compiler-generated header dependencies. Default
CUDA aliases build Rust hosts; all four C oracle sources and explicit
targets remain. Docker installs pinned Rust 1.98.0, and three model-free
IQuest suites join host CI.

Rejected Q8_1 fused MoE, Ling MLA tile/TK=32 and GLM dense-attention paths
are removed with their exclusive dispatch and fixtures. Retained native
SASS matched exactly across these deletions. At `4a6d030d`, the cleanup
removes 1,539 net non-generated lines; another 225,938 deleted lines are two
generated prompt splits, reproducible with the existing generator's
`--render-splits-only`. Local model-directory reclamation is separate
operator evidence, not a repository feature or source-code reduction.

## Known limits and upgrade notes

- MiniMax's raw-book smoke repeated `my...`; a separate fresh official-chat
  prompt of 8,391 tokens answered `READY`. Both observations remain;
  the short chat check does not establish broad generation quality.
- Ling v2's first load was interrupted by host pressure and systemd-oomd.
  A repeat with the documented PSI 40% guard passed. A 2 GiB available-memory
  floor alone does not prevent pressure-based termination; follow the
  [host memory guard](../host-memory-guard.md).
- The 21-artifact smoke does not cover every supported Model Zoo entry.
  Other family, media, MTP, long-context and performance results retain their
  original dated build/artifact/workload scope. No new Metal, maximum-context,
  sustained-load or broad quality qualification is claimed.
- Agent writes reject hardlinked targets, preserve symlink destinations and
  Linux access ACLs/mode/ownership, and reread edits after approval. KV trailer
  replacement rewrites the payload and needs temporary disk space. Foreign
  or legacy identity-less agent KV falls back to saved-text prefill.
- `/data/YoungAi` was absent on the audit host. No new reference-engine
  comparison is claimed; the existing DeepSeek V4.1 port records remain
  scoped to their original references and runs.
