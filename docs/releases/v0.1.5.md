# v0.1.5: VQ families, sampled speculation and standard sampling

This release collects the PRs merged since `v0.1.4`: #111, #114, #115, #118,
#123, #124, #127–#131, and release metadata. Each PR's own validation is its
evidence; this ledger adds no new model qualification.

## Sampling

- [Sampled speculation](../speculative-sampling.md) (#129): drafts verify
  against the request's own sampler in every drafting family, on serial and
  bank lanes.
- [Standard sampling](../serving-contract.md#sampling) (#131): request >
  `--temp`/`--top-p`/`--top-k`/`--min-p` > the model's
  `generation_config.json` (else GGUF `general.sampling.*`) > OpenAI
  defaults; `max_new_tokens` sets the default `max_tokens`. Unseeded requests
  draw a fresh seed (`--seed` reproduces the sequence). The reasoning cap,
  the fixed thinking sampler and tool-syntax argmax are removed. Every native
  draw calls Rust `sample::draw`; the C sampler and the `-c` oracle
  executables are deprecated.

## Upgrade notes

- Requests that omit sampling values now get the model's recommendation, not
  top-p 1.0 / min-p 0.05. Models with `max_new_tokens` in
  `generation_config.json` cap omitted `max_tokens` there (MiMo: 2,048);
  pass `-n` to keep a larger server default.
- Unseeded requests are no longer reproducible across calls; send `seed`
  (or start the server with `--seed`) to reproduce.
- Agent turns with tool results keep thinking until the model closes it.
- `DS4_SERVER_DEFAULT_TEMP` still works and warns; use `--temp`.

## Validation

- `host-parity.yml` steps passed locally on #131 (fmt, clippy, parity,
  serialized workspace tests, V41, IQuest, misc, all-target and native
  checks); the agent bash lifecycle test flaked once and passed on rerun.
- GB10, MiMo VQ, #131's binary: startup defaults came from the model
  (temperature 1, top-p 0.95, `max_tokens` 2,048); on the serial MTP2 lane
  and the continuous bank lane, two unseeded requests differed and two
  `seed: 5` requests matched.
- Release publication requires successful CI on the final merged commit.

## Known limits

- MiMo-V2.6-RL (and its UNCENSORED edition) repeats tool calls in agent
  harnesses; Xiaomi traces it to RL training and fixed it in the MOPD
  checkpoints. Sampling changes here do not change that model behavior.
- DeepSeek V4/Qwen serial CLI verifiers commit one token per step when
  sampling; server lanes refuse MTP there at plan time.
- No new long-context, sustained-load, Metal or broad quality qualification
  is claimed.
